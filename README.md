# Thinking with AI

This project focuses on utilizing artificial intelligence concepts through practical applications. The primary file in this project is a Jupyter notebook that manages a product inventory.

## Project Overview

The `tasks-week6.ipynb` notebook contains Python code that allows users to manage a product inventory. It includes:

- A dictionary to store product names and their corresponding stock counts.
- Functions to check the stock status of products.
- User input handling to check the availability of specific products.

## Instructions for Use

1. Open the `tasks-week6.ipynb` notebook in a Jupyter environment.
2. Run the cells to initialize the inventory and display the stocktake board.
3. Follow the prompts to check the stock status of specific products by entering their names.

This project serves as a practical example of how to apply programming concepts in managing inventory systems.
